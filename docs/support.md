# 墨书技术支持

墨书是一款无账号、本地优先的背单词应用。遇到无法启动、学习数据异常、发音失败或 AI 阅读配置问题，请发送邮件至 [codeless98@163.com](mailto:codeless98@163.com)，并附上设备型号、系统版本、墨书版本和复现步骤。

## 常见问题

### AI 阅读为什么不可用？

AI 阅读需要用户自行配置兼容服务商的 API Key、模型和接口地址。模型费用由对应服务商收取，不包含在应用价格中。

### 为什么单词没有声音？

单词发音通过网络按需获取。请检查网络后重试；基础背词、复习和统计功能仍可离线使用。

### 如何删除数据？

在“设置 → 清理学习数据”中删除学习记录、收藏、统计和阅读历史；在“AI 阅读配置”中删除模型配置和 API Key。

## 数据与开源来源

- 词书数据基于 [Qwerty Learner](https://github.com/RealKai42/qwerty-learner) 的公开词库整理。
- 单词发音由有道词典网络服务按需提供。
- 应用使用 Flutter 及其他开源组件，各组件遵循其随包许可证。
- 墨书源代码与版本记录位于 [gofenix/codeword](https://github.com/gofenix/codeword)。
