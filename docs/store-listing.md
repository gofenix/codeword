# CodeWord 1.0 商店说明

CodeWord 是面向程序员的本地优先背单词应用。核心学习采用四选一、听音辨义、客观拼写和 SM-2 间隔复习；到期词会跨词书统一进入当天学习。

## 付费模式

- iOS App Store 与 Google Play 均采用一次性付费下载。
- 应用内没有订阅、内购或额外解锁费用。

## AI 阅读披露

AI 阅读是可选的 BYOK 功能，需要用户自行提供兼容服务商的 API Key。模型服务费由服务商另行收取，不包含在应用购买价格中。目标词和文章请求仅在用户主动生成时发送给所选服务商。

## 审核备注

- 无账号、无云同步、无广告和用户生成内容。
- 学习数据保存在设备本地。
- AI 阅读未配置时不会发起模型请求。
