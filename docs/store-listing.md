## 应用描述

墨书是一款本地优先的智能背单词应用。它将选择题、可选听音与拼写练习、卡片浏览和 SM-2 间隔复习组织进统一学习流程，到期词会自动进入当天任务。

应用内置多类编程、考试和通用英语词书。学习记录、收藏、统计和阅读历史保存在设备本地，无需账号，也没有广告或云同步。

AI 阅读是可选的 BYOK 功能。用户可以配置自己的兼容模型服务，在主动生成时用正在学习的单词创建文章和理解练习。API Key 保存在系统安全存储中，模型服务费用不包含在应用价格中。

## App 隐私草稿

- 搜索历史：单词发音请求；用于 App 功能，不由墨书账号关联
- 广告、分析、开发者营销：均不使用

## 审核与 TestFlight 备注

- 无注册、登录、云同步、广告和用户生成内容社区。
- 基础学习功能无需配置即可使用；AI 阅读未配置时不会发起模型请求。
- AI 阅读使用用户自备 API Key，不包含开发者密钥。
- iOS 不提供应用内安装更新，所有版本通过 App Store 或 TestFlight 更新。
- 学习数据可在设置页本地删除。
- 应用包含并访问第三方词书和发音内容，开发者确认拥有必要使用权。
