## 应用描述

墨书是一款本地优先的智能背单词应用。它将选择题、可选听音与拼写练习、卡片浏览和 SM-2 间隔复习组织进统一学习流程，到期词会自动进入当天任务。

应用内置多类编程、考试和通用英语词书。学习记录、收藏、统计和阅读历史保存在设备本地，无需账号，也没有广告或云同步。

AI 阅读是可选的 BYOK 功能。用户可以配置自己的兼容模型服务，在主动生成时用正在学习的单词创建文章和理解练习。API Key 保存在系统安全存储中，模型服务费用不包含在应用价格中。

## Google Play Data Safety 草稿

- 数据共享：不向广告商、数据经纪商或开发者自有服务共享数据
- 数据收集：可选 AI 阅读会把目标词、提示词和文章内容发送给用户自行配置的模型服务商；按“其他用户内容 / App 功能”保守披露
- 发音查询：播放发音时会把单词发送给有道服务；按“搜索历史 / App 功能”保守披露
- 安全处理：BYOK API Key 保存在系统安全存储；网络请求使用 HTTPS
- 删除方式：设置页可清除学习数据和 AI 配置；卸载应用会删除应用本地容器
- 跟踪、广告、分析、开发者营销：均不使用
