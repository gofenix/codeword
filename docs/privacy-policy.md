# 墨书隐私政策

更新日期：2026-07-31

墨书是本地优先的背单词应用，不要求注册账号。词书选择、学习记录、收藏、统计和阅读历史默认只保存在当前设备，开发者不建立用户画像，也不使用广告或跟踪技术。

## AI 阅读

AI 阅读是可选的 BYOK（用户自备 API Key）功能。API Key 保存在系统安全存储中，不会写入词书、学习记录或应用安装包。仅当用户主动生成内容时，目标词、提示词、文章内容和所选模型配置才会发送给用户选择的模型服务商。相关数据可能与用户在该服务商的账号关联，其处理方式和费用以用户与服务商之间的协议为准。

## 发音服务

用户播放单词发音时，应用会向有道词典请求对应单词的音频。请求用于提供发音功能，不包含墨书账号信息；网络服务仍可能按照其政策处理 IP 地址和请求日志。

## 应用更新

Android 版本可在用户主动检查或应用启动时查询墨书 GitHub Release，并下载 Android 安装包。iOS 版本不使用应用内安装更新，更新统一通过 App Store 或 TestFlight 提供。

## 数据保存与删除

学习记录、收藏、统计和阅读历史保存在本机。用户可在“设置 → 清理学习数据”删除这些内容，也可在“AI 阅读配置”中删除模型配置和 API Key。卸载应用会删除其本地容器中的数据。
