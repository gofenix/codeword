# CodeWord 隐私政策

更新日期：2026-07-11

CodeWord 是本地优先的背单词应用，不要求注册账号。词书选择、学习记录、收藏、统计和阅读历史默认只保存在当前设备。

## AI 阅读

AI 阅读采用 BYOK（用户自备 API Key）。API Key 保存在系统提供的安全存储中，不会写入词书、学习记录或应用安装包。生成文章或理解题时，目标词、提示词和文章内容会直接发送给用户配置的模型服务商。模型服务商如何处理数据以及产生的费用，以用户与该服务商之间的协议为准。

## 网络请求

播放单词发音时，应用可能向有道词典请求对应的音频。除此之外，基础背词、复习和统计功能可离线使用。

## 数据删除

用户可在“词书 → 设置 → 清理学习数据”删除本机学习记录和阅读历史，也可在 AI 阅读配置中删除保存的模型配置。
