## 真实窗口验证

`scripts/ui-smoke.swift` 通过 LaunchServices 启动交付的 `.app`，使用独立夹具目录。它只检查本应用窗口，不扫描其他应用。使用 Accessibility 操作原生控件并截取本应用窗口：

```sh
swift apps/moshu-native/scripts/ui-smoke.swift \
  apps/moshu-native/dist/Moshu.app <新的独立测试目录>
```

覆盖启动、答题落盘、错题解析、继续重试、五个页面切换和学习会话保留。加 `--article-fixture` 写入合成文章夹具，本次实际验证了离线书架、译文、理解题和目标词详情。测试禁用自动网络发音，不读取真实 AI 密钥、不点击生成。

音频单独检查：有道 `ability` 美音返回 HTTP 200、17240 字节，AVAudioPlayer 成功解码，时长约 0.794 秒。未以机器可听结果代替用户试听。

Release 脚本构建、生成图标和 `.app`、ad hoc 签名并运行 `codesign --verify --deep --strict`。包中包含词书资源、来源说明与 GPL 文本。
