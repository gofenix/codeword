# 数据迁移说明

原生版使用独立标识 `com.codeword.moshu.native`，不直接写入旧版 `com.codeword.codeword` 文档目录。旧版五份 JSON 可通过设置中的文件夹导入；导入没有网络请求，也不访问旧版钥匙串。

## 字段兼容

| 旧数据 | 原生处理 |
| --- | --- |
| 复习记录 | 保留 wordId、整数 easiness、interval、repetitions、dueAt、lastReviewedAt、firstReviewedAt；没有首次学习时间但有最后复习时间时使用 Unix 纪元 |
| 日期 | 接受带时区 ISO 8601 和 Dart 无时区本地日期，保留亚秒精度；无时区记录按导入机器本地时区解释，与旧版语义一致 |
| 活动 | 保留每日计分次数，不把重试和回退重新计入 |
| 用户数据 | 保留收藏、移出、打开次数、分钟与当前词书；未知 wordId 仍保存在数据中 |
| 偏好 | 保留拼写、听音、quiz/swipe 模式 |
| 阅读 | 保留文章 ID、日期、正文、译文、词池、等级与理解题；缺少旧版可选字段时用空值；最新 20 篇 |
| AI 凭据 | 不导入；重新配置到原生版专用钥匙串 |

原始旧文件在解析前逐字节复制到原生目录 `Backups/<唯一标识>`。同时备份导入前的原生文档。解析或验证失败不会修改当前进度，备份仍保留。确认导入时按最后复习时间选择较新的记录，日活动、打开次数和分钟取各自最大值，收藏与移出取并集；阅读按 ID 去重并保留最新 20 篇。重复导入同一份资料不会重复累加。

新词仍按当前文件顺序取；到期复习仍使用旧版“去掉 wordId 最后一个下划线段”的词书归属规则。合并词书里与当前书前缀不同的已学词不会因此自动变成本书到期词，ID 不做重写。

## 原生存储和安全边界

原生版把学习、统计、偏好、非密钥 AI 元数据和阅读放在单份 `moshu-native.json`，根 `schemaVersion` 为 1。日期编码为 Foundation reference-date 秒数（2001-01-01 UTC 起的 Double），从而避免 ISO 格式化丢失亚秒精度；解码器同时接受旧版 ISO 字符串。原生备份由同一解码器恢复，不直接覆盖 Flutter 文件。

每次修改先形成候选状态，通过验证并原子写入成功后才发布到界面；保存失败不会推进题目。文件权限为仅用户可读写。清理操作先备份，再一次原子提交空学习状态，因此没有旧版多文件清理的中间状态；AI 配置、当前书、偏好和音频缓存保留。

以下行为有意与旧版破坏性修复路径不同：

- 旧版 schemaVersion 缺失或低于 2 时会重置复习和活动；此导入器保留可验证记录，不自动删除旧 ID。无效记录拒绝整批导入并保留备份。
- 旧版会清除非 qwerty 前缀记录；此导入器保留这些记录。它们不强行绑定到当前目录，也不重写 ID。
- 旧版用户数据版本高于 2 或存在 `pendingLearningDataClear` 时，先拒绝导入，提示在旧版解决未完成操作。
- 原生文件损坏时进入写保护模式，保留原文件供导出修复，仍可浏览词书；不静默以空文档覆盖。
- 原生版新增显式导入、导出和备份入口，迁移不会自行扫描或覆盖用户真实目录。

这是可验证的一次性迁移方案。两款应用并行使用期间各自保存进度，没有实时同步。
